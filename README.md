# Razer Project Motoko

Página estática en español para el trabajo de Fundamentos de Interacción Persona-Ordenador. Está preparada para publicarse con GitHub Pages: `index.html` se encuentra en la raíz y la hoja de estilos está en `css/style.css`.

## Publicar con GitHub Pages

1. Crea un repositorio público llamado `hardware-cascos` en tu cuenta de GitHub.
2. Sube el contenido de esta carpeta a la rama `main`.
3. En el repositorio, abre **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**, rama `main` y carpeta `/(root)`, y guarda.
5. GitHub publicará el sitio en `https://TU-USUARIO.github.io/hardware-cascos/`.

Las dos fotografías del HTML se cargan desde sus sitios de origen y requieren conexión a Internet.
